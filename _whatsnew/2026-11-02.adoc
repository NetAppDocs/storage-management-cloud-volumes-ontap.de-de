=== Anleitung zum Aktualisieren von ONTAP Hotfixes für bestimmte Cloud Volumes ONTAP Versionen

ONTAP hat die folgenden Hotfixes veröffentlicht, die mit Cloud Volumes ONTAP Versionen 9.14.1, 9.15.1, 9.16.1, 9.17.1, 9.18.1 und 9.19.1 kompatibel sind:

* 9.14.1P18HF1
* 9.15.1P20HF1
* 9.16.1P16HF1
* 9.17.1P11HF1
* 9.18.1P8HF1
* 9.19.1P3HF1


Weitere Informationen finden Sie unter  https://security.netapp.com/advisory/ntap-20261021-0021["NTAP Sicherheitshinweis 20261021-0021"^].

Für Ihre Cloud Volumes ONTAP Systeme werden Sie möglicherweise in der NetApp Console aufgefordert, ein Upgrade auf diese Hotfixes durchzuführen. Diese Hotfixes werden jedoch nur unterstützt, wenn die Version des Console Agenten 4.12.0 oder höher ist. Wenn die Version des Console Agenten älter als 4.12.0 ist, ignorieren Sie die Aufforderung.

https://docs.netapp.com/us-en/console-setup-admin/whats-new.html#console-agent-4-12-0["Console Agent 4.12.0"^]
