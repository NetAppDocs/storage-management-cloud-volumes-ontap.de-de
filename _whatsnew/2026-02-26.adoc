=== Unterstützung für Google Infrastructure Manager für Bereitstellungen im privaten Modus

Cloud Volumes ONTAP 9.16.1 und höher unterstützen jetzt https://docs.cloud.google.com/infrastructure-manager/docs/overview["Google Cloud Infrastructure Manager"^] (IM) anstelle von https://docs.cloud.google.com/deployment-manager/docs/deprecations["Cloud Deployment Manager"^] (DM) für neue Deployments im privaten Modus in Google Cloud. Google stellt den Deployment Manager als Infrastrukturdienst zugunsten des fortschrittlicheren Infrastructure Manager ein.

Ab dem 25. Februar 2026 verwendet Cloud Volumes ONTAP den Infrastructure Manager für neue und bestehende Deployments im privaten Modus. Der grundlegende Workflow hängt von Ihrem Szenario ab:

[cols="1,4,1,1,1,1"]
|===
| Szenario | Aktion | Neue APIs für den Agent | Neue Berechtigungen für den Agent | Neue Google Cloud APIs für Cloud Volumes ONTAP | Dokumentressourcen 


| Vorhandener Agent und bestehende Bereitstellung im privaten Modus | Um den Console agent auf die neueste Version zu aktualisieren, können Sie das Installationsprogramm von der NetApp Support Site herunterladen und den Agenten anschließend manuell auf Ihrem Host installieren, damit er Infrastructure Manager APIs verwenden kann. Anschließend können Sie die vorhandenen Cloud Volumes ONTAP Systeme für die Verwendung von Infrastructure Manager konvertieren.  a|

* Cloud Quotas API
* Cloud Build API

Bei Bereitstellungen im privaten Modus müssen Sie einige Konfigurationsänderungen vornehmen, damit Cloud Volumes ONTAP den Infrastructure Manager verwenden kann. Informationen hierzu finden Sie unter  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/reference-networking-gcp.html#infrastructure-manager-configuration-in-private-mode-or-protected-environments["Infrastructure Manager Konfiguration im privaten Modus oder in geschützten Umgebungen"^].
