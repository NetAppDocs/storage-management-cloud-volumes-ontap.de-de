= Informationen zu den Automatisierungsoptionen von Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
DevOps-Teams nutzen verschiedene Tools, um die Einrichtung und Administration ihrer Laufzeitumgebungen im Rechenzentrum zu automatisieren. Neben NetApp Console können für die Automatisierung von Cloud Volumes ONTAP mehrere dieser Technologien verwendet werden, darunter NetApp Console APIs, ONTAP CLI-Prozeduren und Automatisierungstools wie Ansible und Terraform. Die externen Automatisierungstools basieren üblicherweise auf einem Infrastructure as Code (IaC)-Design.

Diese  https://labondemand.netapp.com/["Lab on Demand"^]Funktion dient zur Automatisierung von Cloud Volumes ONTAP.



[[netapp-console-apis]]
== NetApp Console-APIs

Die NetApp Console stellt REST-APIs bereit, mit denen Sie Cloud Volumes ONTAP-Ressourcen programmatisch verwalten können. Die APIs unterstützen Vorgänge wie das Erstellen und Verwalten von Cloud Volumes ONTAP-Systemen sowie das Hinzufügen von Aggregaten und Volumes auf Amazon Web Services (AWS), Microsoft Azure (Azure) und Google Cloud. Die verfügbaren API-Aufrufe variieren je nach Cloud-Anbieter und Bereitstellungstyp, einschließlich Einzelknoten- und Hochverfügbarkeitskonfigurationen (HA).

Mit den Cloud Volumes ONTAP API-Workflows lässt sich eine typische Bereitstellung und die anschließende Speicherverwaltung automatisieren. Einige Workflows umfassen die Vorbereitung der Bereitstellung, die Erstellung eines Systems und die Verwaltung von Storage sowie anbieterspezifische Workflows für AWS, Azure und Google Cloud.

[[ontap-cli]]
== ONTAP CLI

Sie können die ONTAP CLI für verschiedene Verwaltungsaufgaben von Cloud Volumes ONTAP verwenden. Die verfügbaren Verfahren und Befehle variieren je nach Funktion und Cloud-Anbieter. Die Aktualisierung von Cloud Volumes ONTAP sollte nicht mit der ONTAP CLI oder ONTAP System Manager durchgeführt werden. Aktualisierungen werden über die NetApp Console durchgeführt.

|===
| Aktivitäten | CLI-Prozeduren oder Befehle | Referenzen 


| Die Verwaltung der Verschlüsselungsschlüssel für Cloud Volumes ONTAP kann konfiguriert werden. | AWS KMS-, Azure Key Vault- oder Google Cloud KMS-Befehle in der ONTAP CLI  a| 
link:task-aws-key-management.html["AWS KMS Schlüsselverwaltung konfigurieren"] link:task-azure-key-vault.html["Konfiguration der Schlüsselverwaltung in Azure Key Vault"] link:task-google-key-manager.html["Konfiguration der Google Cloud KMS Schlüsselverwaltung"]



| Ereignisziele und -routen des Event Management Systems (EMS) werden konfiguriert. | EMS Konfigurationsbefehle in der ONTAP CLI | link:task-configure-ems.html["EMS konfigurieren"] 


| Für einen bestehenden Cloud Volumes ONTAP Cluster wird ein NTP-Server konfiguriert. | `cluster time-service ntp server create` | link:task-sync-time.html["NTP-Server konfigurieren"] 


| Die Datenkomprimierung wird beim Erstellen eines Volumes deaktiviert, wenn die Speichereffizienz deaktiviert ist. | ONTAP CLI Befehle zur Volumeffizienz  a| 
link:concept-flash-cache.html["Überprüfung der Speichereffizienzoptionen"] link:reference-limitations-aws.html["Überprüfung der AWS-Speichereffizienzbeschränkung"]



| Zusätzliche LUNs werden erstellt. | Befehle zum Erstellen von LUNs in der ONTAP CLI | link:task-create-volumes.html["Erstellen von Volumes und zusätzlichen LUNs"] 


| Erstellung von Volumes mit deaktiviertem WORM oder von Snapshot-Kopien für SnapLock Volumes, je nach Bedarf. | Befehle zur Volume- und Snapshot-Verwaltung in der ONTAP CLI  a| 
link:concept-worm.html["WORM Storage verwalten"] link:reference-worm-snaplock.html["Snapshot Kopien für WORM-Speicher werden erstellt"]



| Das NVFAIL-Verhalten kann so konfiguriert werden, dass der Zugriff auf Daten nach einem Datenverlustereignis verhindert wird, bis das Problem behoben ist. | NVFAIL Konfigurationsbefehle in der ONTAP CLI | link:concept-write-speed.html["NVFAIL konfigurieren"]

[[terraform]]
== Terraform

Terraform ist ein Open-Source-Orchestrierungstool, das deklarative Konfigurationsdateien verwendet. NetApp bietet einen Terraform-Provider für Cloud Volumes ONTAP. Sie können es verwenden, um Ihre Infrastruktur mit IaC zu automatisieren und zu integrieren. Weitere Informationen finden Sie unter  https://registry.terraform.io/providers/NetApp/netapp-cloudmanager/latest["NetApp Terraform Provider"^].
