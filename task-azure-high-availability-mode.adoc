= Aktivieren Sie den Hochverfügbarkeitsmodus für Cloud Volumes ONTAP in Azure
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Zur Reduzierung ungeplanter Failover-Zeiten und zur Unterstützung von NFSv4 steht für Ihr Cloud Volumes ONTAP HA Paar der Microsoft Azure Hochverfügbarkeitsmodus (HA) zur Verfügung. Dieser Modus kann für CIFS- und NFSv4-Clients bei ungeplanten Failovern ein Recovery Time Objective (RTO) von 60 Sekunden bieten.

Ab Cloud Volumes ONTAP 9.10.1 haben wir die ungeplante Failover-Zeit für Cloud Volumes ONTAP HA-Paare in Microsoft Azure reduziert und Unterstützung für NFSv4 hinzugefügt. Damit diese Erweiterungen für Cloud Volumes ONTAP verfügbar sind, müssen Sie die HA-Funktion in Ihrem Azure Abonnement aktivieren.

.Informationen zu diesem Vorgang
Die NetApp Console zeigt eine Aufforderung an, wenn diese Funktion in einem Azure-Abonnement aktiviert werden muss. Folgendes ist zu beachten:

* Diese Funktion arbeitet mit ONTAP zusammen, um die von NFS-Clients bei ungeplanten Failovern beobachtete Ausfallzeit von Applikationen zu reduzieren. Die Aktivierung dieser Funktion weist nicht auf ein Problem mit der Verfügbarkeit Ihres Cloud Volumes ONTAP HA-Paars hin.
* Die Aktivierung dieser Azure-Funktion beeinträchtigt Cloud Volumes ONTAP HA-Paare nicht.
* Die Aktivierung dieser Funktion in Ihrem Azure-Abonnement hat keine Auswirkungen auf andere VMs in Ihrer Umgebung oder auf Einzelknotensysteme innerhalb desselben Abonnements.
* Bei Failovers verwendet Cloud Volumes ONTAP einen internen Azure Load Balancer für Cluster- und SVM-Management-LIFs, die CIFS- und NFS-Clients bedienen.
* Nach der Aktivierung des HA-Modus durchsucht die Console das System alle 12 Stunden, um die internen Regeln des Azure Load Balancer zu aktualisieren.


.Schritte
Die Aktivierung der Funktion erfolgt über die Azure CLI als Azure-Benutzer mit _Owner_-Berechtigungen.

. https://docs.microsoft.com/en-us/azure/cloud-shell/quickstart["Greifen Sie über das Azure-Portal auf die Azure Cloud Shell zu"^]
. Registrieren Sie die Funktion für den Hochverfügbarkeitsmodus:
+
[source, azurecli]
----
az account set -s AZURE_SUBSCRIPTION_NAME_OR_ID
az feature register --name EnableHighAvailabilityMode --namespace Microsoft.Network
az provider register -n Microsoft.Network
----
. Überprüfen Sie optional, ob die Funktion jetzt registriert ist:
+
[source, azurecli]
----
az feature show --name EnableHighAvailabilityMode --namespace Microsoft.Network
----
+
Die Azure CLI sollte ein Ergebnis ähnlich dem folgenden zurückgeben:

+
[listing]
----
{
  "id": "/subscriptions/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/providers/Microsoft.Features/providers/Microsoft.Network/features/EnableHighAvailabilityMode",
  "name": "Microsoft.Network/EnableHighAvailabilityMode",
  "properties": {
    "state": "Registered"
  },
  "type": "Microsoft.Features/providers/features"
}
----
