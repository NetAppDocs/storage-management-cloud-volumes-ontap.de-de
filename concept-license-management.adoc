= Informationen zur BYOL-Lizenzierung in Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Bring-Your-Own License (BYOL) ist ein Cloud Volumes ONTAP Abrechnungsmodell, bei dem eine Lizenz direkt von NetApp erworben wird, anstatt ein Abonnement über einen Cloud-Marktplatz zu nutzen.

BYOL ist für Standard-Mode- und Private-Mode-Bereitstellungen verfügbar, vorbehaltlich Verfügbarkeitsbeschränkungen. Die Verwaltung von BYOL-Lizenzen erfolgt im Abschnitt *Lizenzierung und Abonnements* der NetApp Console unter *Direktlizenzen*. Jede Lizenz ist Ihrem Unternehmen und bestimmten NetApp Support Site-Anmeldeinformationen zugeordnet.

* NetApp hat den Kauf, die Erweiterung und die Erneuerung von BYOL-Lizenzen für Standard-Mode-Bereitstellungen mit gültigen Marketplace-Abonnements eingeschränkt. Weitere Informationen finden sich unter  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html#restricted-availability-of-byol-licensing-for-cloud-volumes-ontap["Eingeschränkte Verfügbarkeit der BYOL-Lizenzierung für Cloud Volumes ONTAP"^].
* NetApp stellt die knotenbasierte Lizenzierung zugunsten einer kapazitätsbasierten Lizenzierung schrittweise ein. Knotenbasierte Lizenzen sind weiterhin für eine begrenzte Anzahl bestehender Deployments verfügbar, einschließlich einiger USPS-Kunden-Deployments und Deployments in China. Weitere Informationen finden sich unter  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/concept-licensing.html#end-of-availability-of-node-based-licenses["Ende der Verfügbarkeit von knotenbasierten Lizenzen"^].




[[byol-deployment-modes]]
== BYOL-Bereitstellungsmodi

[role="tabbed-block"]
====
.Bereitstellungen im Standardmodus
--
* Statt BYOL bevorzugt NetApp jährliche oder Pay-as-you-go (PAYGO) Marktplatzabonnements zur Abrechnung Ihres Verbrauchs.
* Standard-Mode-Bereitstellungen verwenden im Allgemeinen kapazitätsbasierte Lizenzen anstelle von node-basierten Lizenzen. Nur eine begrenzte Anzahl bestehender Standard-Mode-Bereitstellungen verwendet node-basierte Lizenzen.


--
.Bereitstellungen im privaten Modus
--
* Bereitstellungen im privaten Modus basieren vollständig auf BYOL-Lizenzen, da Marketplace-Abonnements im privaten Modus nicht verfügbar sind.
* Für neue Implementierungen werden kapazitätsbasierte Essentials Pakete anstelle von knotenbasierten Lizenzen verwendet. Knotenbasierte Lizenzierung wird von einigen älteren Private-Mode-Implementierungen verwendet.


--
====


[[compare-byol-license-types-in-private-mode]]
=== BYOL-Lizenztypen im privaten Modus im Vergleich

Die folgende Tabelle fasst die Unterschiede zwischen kapazitätsbasierten und knotenbasierten Lizenzen im privaten Modus zusammen.

[cols="25,37,38"]
|===
| Funktion | Kapazitätsbasierte Lizenzen | Knotenbasierte Lizenzen 


| Bereitstellungsunterstützung  a| 
Neue Bereitstellungen im privaten Modus unterstützen ausschließlich kapazitätsbasierte Lizenzen, insbesondere das Essentials Paket.
 a| 
Neue Bereitstellungen im privaten Modus unterstützen keine knotenbasierten Lizenzen. Nur eine begrenzte Anzahl bestehender knotenbasierter Bereitstellungen kann diese weiterhin nutzen.



| Kauf  a| 
Ein kapazitätsbasiertes BYOL Essentials Paket von NetApp kann erworben und während der Bereitstellung dem System zugewiesen werden.
 a| 
Wenn bereits eine private Bereitstellung mit einer knotenbasierten Lizenz vorhanden ist, kann diese durch den Kauf eines Essentials Pakets von NetApp auf kapazitätsbasierte Lizenzierung umgestellt werden.



| Kapazität  a| 
Die ersten 500 GiB verbrauchter Kapazität werden nicht auf Ihre Lizenzgebühren angerechnet. Zusätzliche Pakete können erworben werden, wenn der Bedarf an Arbeitslasten steigt.
 a| 
Eine knotenbasierte Lizenz bietet bis zu 368 TiB Kapazität für einen einzelnen Knoten oder ein HA-Paar. Um mehr als 368 TiB einem Cloud Volumes ONTAP System zuzuweisen, ist der Erwerb mehrerer Lizenzen erforderlich. Zum Beispiel ermöglichen zwei Lizenzen bis zu 736 TiB und vier Lizenzen bis zu 1,4 PiB.



| Umfang  a| 
Die kapazitätsbasierte Lizenzierung greift auf einen gemeinsamen Kapazitätspool Ihrer Cloud Volumes ONTAP Systeme zurück. Die verfügbare Kapazität kann entsprechend dem sich ändernden Speicherbedarf neu verteilt werden.
 a| 
Jede knotenbasierte Lizenz gilt für ein Cloud Volumes ONTAP System und stellt diesem System eine feste Kapazität zur Verfügung.



| Übertragbarkeit  a| 
Jede kapazitätsbasierte Lizenz ist einem Console-Konto zugeordnet. Systeme, die unter diesem Konto erstellt werden, können die Lizenzkapazität und die Seriennummer gemeinsam nutzen. Beispielsweise kann eine 5-TiB-Lizenz zwei Systeme mit jeweils 2,5 TiB oder ein System mit 5 TiB unterstützen. Die Lizenzseriennummer ist in der Console sichtbar, und dieselbe Lizenz kann mehreren Systemen unter demselben Konto zugewiesen werden.
 a| 
Sie können eine node-basierte BYOL-Lizenz übertragen, indem Sie das vorhandene System löschen und die Lizenz zur Erstellung eines neuen Systems verwenden. Nur _cloud-agnostische_ Seriennummern funktionieren über verschiedene Cloud-Anbieter hinweg. Diese Seriennummern beginnen mit dem Präfix _908xxxx_.

|===


[[manage-and-renew-byol-licenses]]
== BYOL-Lizenzen verwalten und erneuern



[[renew-a-byol-license]]
=== Eine BYOL-Lizenz verlängern

Wenden Sie sich an einen NetApp Vertreter, um Ihre BYOL-Lizenz zu verlängern. Die Konsole ruft die verlängerte Lizenz automatisch ab und installiert sie auf dem Cloud Volumes ONTAP System.

Falls die Konsole nicht über eine sichere Internetverbindung auf die Lizenzdatei zugreifen kann, die Lizenzdatei herunterladen und link:task-manage-node-licenses.html["manuell in die Konsole hochladen"].

Informationen zur Verwaltung der mit der NetApp Support Site verknüpften Anmeldeinformationen in der Console finden sich unter  https://docs.netapp.com/us-en/console-setup-admin/task-adding-nss-accounts.html["NSS-Anmeldeinformationen verwalten, die mit der NetApp Console verknüpft sind"^].



[[respond-to-an-expiration-warning]]
=== Auf eine Ablaufwarnung reagieren

Die Konsole zeigt 30 Tage vor Ablauf einer knotenbasierten Lizenz und erneut zum Zeitpunkt des Ablaufs eine Warnung an. Das Cloud Volumes ONTAP System kann ausgewählt werden, um die Warnung einzusehen und die Lizenz zu erneuern.

image:screenshot_warning.gif["Screenshot: Zeigt ein Cloud Volumes ONTAP -System mit einem Warnsymbol.  Das Symbol zeigt an, dass eine Aktion erforderlich ist."]

Wenn Sie Organisationsadministrator oder Kontoadministrator sind und die Option aktiviert haben, enthält die Konsole eine Warnung zum Ablauf der Lizenz im Cloud Volumes ONTAP Bericht und sendet Ihnen diese per E-Mail zu.

Wenn die Lizenz nicht vor ihrem Ablauf verlängert wird, fährt das Cloud Volumes ONTAP-System herunter. Ein Neustart des Systems ohne Verlängerung der Lizenz führt dazu, dass es erneut heruntergefahren wird.
